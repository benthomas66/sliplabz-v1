## Standing governance rules (chat-independent)

1. **One chat** (the governor) commands the terminal agent. All others propose. The governor is read-only: inspects, tests, rules; does not implement/commit/push.
2. **Two-step review:** report, then FILE INSPECTION before approval. Screenshot-parity (Parity §5) is a founder-mandated pass condition on every surface ticket; the implementation environment cannot produce screenshots, so the founder deploys and reviews on device. Never waived.
3. **One approved ticket per commit**; exact-path staging by name; commit authorizations are files, never chat paste.
4. **Tickets pin the expected HEAD and halt on mismatch. No next ticket until the previous commit is confirmed.**
5. **"Safe by absence of callers" is rejected** — require impossible by construction.
5b. **POSITIVE-PERSISTENCE PROOF BEFORE PAID RETRIEVAL (added 2026-08-04 after GAP-39).** *No paid retrieval execution is authorized until a positive-persistence test exercises the exact effectful operator wiring and proves that a successful provider response produces the required owned database rows.* A write-free dry-run proves only **inability to spend/write accidentally** and **planning behavior** — **not** that the effectful path supplies correct persistence inputs or produces positive output. The test **must exercise the same dependency assembly and call path as `scripts/v1_op_8b_batch.ts --apply`** (recorded fixture + controlled DB), **not** a lower-level function called with hand-corrected arguments. *Provenance: the governor accepted the weaker (dry-run-only) proof for V1-OP-8b batch-1; 400 credits were spent for zero rows. This rule closes that gap.*
   **SHARPENED (added 2026-08-04 after GAP-40):** *A positive-persistence test asserts the **persisted DB row** carries **every field the persist contract claims to persist** — not an intermediate object, trail, or in-memory report. Verified by reading the actual INSERT and asserting on the bound/read-back row.* **This is an explicit checklist item at every future persist audit.** (A passing test that asserted the trail object let two quota columns land null through a live paid run.) **Corollary — completeness sweep:** at each persist audit, enumerate every contract field × every table written and confirm each is (a) in the contract, (b) bound in the INSERT, and (c) asserted on the persisted row — or explicitly documented as intentionally not persisted.
